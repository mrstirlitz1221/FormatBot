# FormatBot — Universal File Toolkit

FormatBot — Telegram-бот для работы с файлами: конвертация, сжатие и редактирование прямо в чате.
Интерфейс построен на **Telegram Widgets** (Bot API 10.4): интерактивные карточки внутри сообщений.
Для клиентов без виджетов есть классические inline-кнопки.

Вся обработка выполняется локально, без платных API и сторонних сервисов.

Бот принимает любые файлы и определяет их тип. Действия доступны для изображений, PDF, документов, аудио и видео.

## Возможности (работает сейчас)

**Изображения:** JPG, PNG, WEBP, BMP, GIF (включая анимацию), TIFF, ICO, HEIC/HEIF, AVIF.

- Конвертация между всеми форматами и в PDF; прозрачность сохраняется там, где формат её поддерживает
  (в JPG/BMP — заливка белым); выбор качества для JPG/WEBP/HEIC/AVIF.
- Сжатие: «Максимальное качество», «Баланс», «Максимальное сжатие», «Свои настройки»
  (качество 10–100 и ограничение разрешения). Для PNG — без потерь или палитра до 256 цветов с прозрачностью.
  BMP сжимается в PNG без потерь. Разрешение никогда не увеличивается.
- Инструменты: изменение размера (проценты, пресеты, свой размер), обрезка (соотношения сторон или своя область),
  поворот/отражение, чёрно-белое, в PDF, удаление метаданных (EXIF/GPS/XMP; цветовой профиль сохраняется),
  оптимизация.
- Результат: файл документом (без пережатия Telegram) + карточка с исходным и итоговым размером, процентом,
  сэкономленным объёмом и временем. Все числа — по реальным размерам файлов. Если сжатие не уменьшило файл,
  бот так и говорит и не присылает копию большего размера.

**PDF:**

- Конвертация: PDF → DOCX (текст с размерами и начертанием, заголовки, таблицы, картинки; вёрстка
  воспроизводится приблизительно, а не 1:1), PDF → TXT, PDF → PNG/JPG (несколько страниц — архивом ZIP).
- Сжатие: «Лёгкое» (без потерь: структура, шрифты, метаданные), «Среднее» (картинки до 150 dpi, JPEG 75),
  «Сильное» (до 96 dpi, JPEG 55). Текст остаётся текстом.
- Инструменты: объединить PDF (дошлите файлы в чат и нажмите «Готово»), разделить по страницам,
  в изображения, извлечь текст, повернуть, удалить / извлечь страницы, изменить порядок
  (страницы вводятся сообщением: `2, 5-7`). Изображения → PDF — в инструментах изображений («Несколько…»).

**Документы** (DOC, DOCX, ODT, RTF, TXT, HTML, XLS, XLSX, ODS, CSV, PPT, PPTX, ODP):

- С LibreOffice: текстовые ↔ PDF/DOCX/ODT/RTF/TXT/HTML, таблицы → PDF/XLSX/ODS/CSV, презентации → PDF/PPTX/ODP.
- Без LibreOffice тоже работает: TXT → PDF/DOCX, CSV → PDF, HTML → PDF, DOCX → TXT (кириллица поддерживается).
- Сжатие DOCX/XLSX/PPTX/ODT/ODS/ODP: переупаковка ZIP-контейнера с максимальным сжатием и оптимизацией
  встроенных картинок; имена и порядок частей сохраняются, документ остаётся валидным.
- Бот показывает только те конвертации, которые реально доступны (с учётом установленного LibreOffice).

**Аудио** (MP3, WAV, FLAC, AAC, OGG, M4A, OPUS; голосовые сообщения):

- Конвертация между всеми форматами; для MP3/AAC/M4A/OGG/OPUS — битрейт 320/192/128/96 kbps.
- Сжатие: 320/192/128/96 kbps. Бот не предлагает битрейт выше исходного и предупреждает о потерях при переходе
  из WAV/FLAC в форматы с потерями. Конвертация MP3 → WAV честно называется конвертацией, а не сжатием.
- Инструменты: обрезка (`0:10-0:45`), частота дискретизации, моно/стерео.

**Видео** (MP4, AVI, MOV, MKV, WEBM, GIF):

- Конвертация между контейнерами; если кодеки подходят, потоки копируются без перекодирования (быстро и без потерь).
  Видео → GIF (палитра в два прохода, 12 fps, до 480px, до 20 с); анимированный GIF → MP4/WEBM.
- Сжатие: «Маленький размер» (≤480p, CRF 30, ≤1 Мбит/с, звук 96k), «Баланс» (≤720p, CRF 26, ≤2,5 Мбит/с),
  «Высокое качество» (≤1080p, CRF 22, ≤6 Мбит/с), «Свои настройки» (качество → CRF, разрешение).
  Разрешение никогда не увеличивается; ограничивается короткая сторона, поэтому вертикальные видео тоже корректны.
- Инструменты: извлечь аудио (MP3/M4A/WAV), извлечь кадры (каждую секунду, каждые 5 с или 10 кадров — ZIP),
  обрезать, в GIF, изменить разрешение и FPS.
- Прогресс обработки в процентах в карточке задачи; отмена немедленно завершает FFmpeg.

**Общее:** очередь задач с отменой, история с пагинацией, настройки (язык RU/EN, качество и режим сжатия по умолчанию,
уведомления, режим интерфейса, очистка истории), статистика.

## Установка на Windows

1. **Python 3.11+** — https://www.python.org/downloads/ (при установке отметьте «Add python.exe to PATH»).
   Проверка: `py -3.12 --version`.
2. **Создайте бота** в Telegram: откройте [@BotFather](https://t.me/BotFather), команда `/newbot`,
   задайте имя и username. BotFather пришлёт токен вида `123456789:AA...` — это `BOT_TOKEN`.
3. **Настройте проект** (в папке проекта, PowerShell):

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
```

4. Откройте `.env` в блокноте и вставьте токен после `BOT_TOKEN=`.
5. **Запуск:**

```powershell
.venv\Scripts\python.exe bot.py
```

В логе появится `Authorized as @имя_бота`. Откройте бота в Telegram и отправьте `/start`.

### Внешние программы

Для изображений и PDF ничего ставить не нужно. Для офисных форматов нужен LibreOffice, для аудио и видео — FFmpeg (без него эти действия скрываются):

- **FFmpeg**: `winget install Gyan.FFmpeg` или архив с https://ffmpeg.org/download.html (сборки gyan.dev или BtbN).
  Распакуйте куда угодно, например `E:\Programs\ffmpeg`, и укажите в `.env` `FFMPEG_PATH` и `FFPROBE_PATH` (или добавьте папку `bin` в PATH).
- **LibreOffice**: https://www.libreoffice.org/download/ или `winget install TheDocumentFoundation.LibreOffice`.
  Бот сам найдёт `C:\Program Files\LibreOffice\program\soffice.exe`. Установить на другой диск:
  `winget install TheDocumentFoundation.LibreOffice --location E:\Programs\LibreOffice --custom "INSTALLLOCATION=E:\Programs\LibreOffice"`,
  затем в `.env`: `SOFFICE_PATH=E:\Programs\LibreOffice\program\soffice.exe`.
- **Ghostscript** (необязательно, для сильного сжатия PDF): https://ghostscript.com/releases/gsdnld.html.

Если программа установлена в нестандартное место, укажите путь в `.env` (`FFMPEG_PATH`, `SOFFICE_PATH`, ...).
При старте бот пишет в лог, какие программы найдены.

## Тесты

```powershell
.venv\Scripts\python.exe -m pytest
```

Тесты (около 180): определение типов, конвертация и сжатие с проверкой реальных выходных файлов (открываются Pillow/PyMuPDF),
PDF-инструменты, сжатие PDF и офисных файлов, PDF→DOCX, конвертации через LibreOffice
(пропускаются, если LibreOffice не установлен), аудио и видео на файлах, сгенерированных FFmpeg
(пропускаются без FFmpeg), отмена с завершением FFmpeg, валидация и защита от path traversal/ZIP-бомб/«бомб распаковки» изображений, очередь задач и отмена,
лимиты виджетов (32 КБ / 4096 Б после zlib-9, chat_data ≤ 1024 Б, запрещённые профилем элементы),
и сквозной тест бота: `/start` → загрузка файла → `widget_query` → задача → документ → обновление виджета,
отклонение некорректных и чужих действий, fallback на кнопки.

Сквозной тест использует **фейковый Bot API**, а не реальный Telegram. Отображение виджетов в настоящем
клиенте Telegram нужно проверить вручную на своём боте (см. ниже).

## Telegram Widgets: как это устроено

- Виджет — HTML+CSS+JS до 32 КБ (до 4096 Б после сжатия), выполняется в песочнице QuickJS без сети.
  HTML фиксируется при отправке; меняется только состояние (`chat_data`, ≤ 1024 Б), которое пишет бот.
- Кнопка в виджете вызывает `TelegramWidget.request(data)` (≤ 64 байта) → боту приходит `widget_query` →
  бот проверяет действие по своему состоянию в БД (`widget_sessions`) и отвечает `answerWidgetQuery` за ≤ 15 с.
  Длинная работа идёт в очереди, а карточка задачи обновляется через `editMessageWidgetData`.
- Каждый экран — отдельное небольшое сообщение-виджет: меню, карточка файла, конвертация, сжатие,
  инструменты, задача (ожидание → прогресс → результат со сравнением размеров).
- Тексты виджетов локализуются на сервере перед отправкой.
- Ограничения Telegram: в production виджеты работают **только в личном чате с ботом**, их нельзя переслать;
  не более 5 запросов за 5 секунд на пользователя; нет ввода текста — поэтому параметры вроде своего размера
  вводятся обычным сообщением в чат.
- aiogram 3.31.0 (последний на момент разработки) поддерживает Bot API 10.3, поэтому методы и типы виджетов
  добавлены отдельным адаптером `api/widget_api.py` поверх обычного HTTP API — без патчей aiogram.

**Если виджеты не отображаются** (старый клиент) — нажмите «Классические кнопки» в приветствии или переключите
интерфейс в `/settings`. Если `sendWidget` возвращает ошибку, бот сам переходит на кнопки.

## Ограничения Telegram Bot API на файлы

- Бот может **скачать** файл до **20 МБ** (`getFile`) и **отправить** до **50 МБ**.
- Фото, отправленные как «фото», Telegram уже пережал — для лучшего качества отправляйте файлом.
- Чтобы работать с файлами до 2000 МБ, можно поднять **локальный Telegram Bot API Server**
  (https://github.com/tdlib/telegram-bot-api) и указать `TELEGRAM_API_URL` и `MAX_FILE_SIZE_MB`.
  Это необязательная опция.

## Безопасность

Тип файла определяется по содержимому, а не по расширению; входной файл сохраняется под фиксированным именем
в отдельной папке задачи и удаляется сразу после обработки; имена файлов очищаются; изображения больше 90 Мп
отклоняются; DOCX/XLSX/PPTX/ODT проверяются на ZIP-бомбы до обработки; каждое действие проверяется по серверному
состоянию и владельцу; LibreOffice запускается списком аргументов без shell, с отдельным профилем на задачу,
таймаутом и принудительным завершением всего дерева процессов. Токен не хранится в коде и маскируется в логах.
